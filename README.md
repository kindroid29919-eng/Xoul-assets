# Xoul-assets

Game art assets for the Xoul project — weapons, icons, and UI elements — with an automated metadata generator.

---

## Repository layout

```
weapons/
  atk/  swords/ axes/ bows/ polearms/
  def/  shields/ armor/
  hp/   rings/ pendants/ charms/
    └── common/ rare/ epic/ legendary/  ← weapon images go here

icons/
  weapon_types/  rarity/  stats/

ui/
  backgrounds/  frames/  banners/  misc/

docs/
  weapon_database.json   ← hand-curated reference (ATK weapons)

weapons.json             ← auto-generated by the Weapon Generator
scripts/
  weapon-generator/      ← the tool (see below)
```

---

## Weapon Generator

The tool scans `weapons/` and writes every weapon's metadata to **`weapons.json`** automatically.

### Quick start

```bash
npm install        # first time only
npm run weapons    # opens the interactive menu
```

### Menu options

| # | Option | What it does |
|---|--------|--------------|
| 1 | Scan for new weapons | Appends new weapons to `weapons.json`; existing entries are untouched |
| 2 | Rebuild weapons.json | Clears and fully regenerates all entries (new random stat values) |
| 3 | Edit stat ranges | Change the min/max base-stat ranges per rarity |
| 4 | Configure GitHub repository | Set username, repo name, branch, and assets path for image URLs |
| 5 | Validate assets | Check for invalid paths, duplicate IDs, and missing images |
| 6 | Exit | |

### Non-interactive flags (for CI or scripting)

```bash
npm run weapons:scan      # scan & append new weapons
npm run weapons:rebuild   # full rebuild
npm run weapons:validate  # validate only
```

### Intended workflow

1. Drop image files into the correct folder:  
   `weapons/<stat>/<type>/<rarity>/<filename>.png`  
   e.g. `weapons/atk/swords/epic/odin_blade.png`
2. Run `npm run weapons` → choose **Scan for new weapons**.
3. The tool detects the new file, generates all metadata, assigns a random base-stat value, builds the GitHub Raw image URL, and writes the entry to `weapons.json`.

### Weapon entry shape

```json
{
  "id":            "odin_blade",
  "name":          "Odin Blade",
  "rarity":        "epic",
  "weaponType":    "sword",
  "baseStat":      "atk",
  "baseStatValue": 11,
  "image":         "https://raw.githubusercontent.com/<user>/<repo>/<branch>/weapons/atk/swords/epic/odin_blade.png"
}
```

### Configure the GitHub image URL

Run `npm run weapons` → option **4. Configure GitHub repository**, or edit  
`scripts/weapon-generator/config.json` directly:

```json
{
  "github": {
    "username":   "your-username",
    "repository": "xoul-assets",
    "branch":     "main",
    "assetsDir":  ""
  }
}
```

### Stat ranges

Ranges are stored in `scripts/weapon-generator/config.json` and editable from menu option 3.

| Stat | Common | Rare | Epic | Legendary |
|------|--------|------|------|-----------|
| ATK  | 1–4    | 5–8  | 9–13 | 14–19     |
| DEF  | 1–3    | 4–7  | 8–10 | 11–13     |
| HP   | 6–12   | 13–21 | 22–35 | 35–50   |

### Valid weapon types per stat

| Stat | Types |
|------|-------|
| ATK  | sword, axe, bow, polearm |
| DEF  | shield, armor |
| HP   | ring, pendant, charm |

## File naming conventions

- Lowercase, underscores for spaces.
- Include type in the name where useful.
- Do **not** include rarity in the filename (it comes from the folder).

Examples:
```
weapons/atk/swords/common/bronze_sabre.png
weapons/def/shields/epic/aegis_wall002.png
weapons/hp/rings/legendary/dragon_ring01.png
```

---

## Supported image formats

`.png`, `.jpg`, `.jpeg`, `.webp`
